# Sistema de Banco de Dados - LAN House

Projeto acadêmico de modelagem e implementação de banco de dados para gerenciamento de uma LAN House.

## Funcionalidades modeladas

- Controle de clientes
- Controle de computadores
- Sessões de uso
- Funcionários
- Produtos
- Vendas
- Itens de venda
- Torneios
- Participação em torneios
- Logs de auditoria

## Tecnologias utilizadas

- MySQL
- SQL
- Modelo Entidade Relacionamento (DER)

## Estrutura do Projeto

- ddl.sql → criação das tabelas
- inserts.sql → dados iniciais
- consultas.sql → consultas SQL
- modelo-conceitual.png → DER do sistema
